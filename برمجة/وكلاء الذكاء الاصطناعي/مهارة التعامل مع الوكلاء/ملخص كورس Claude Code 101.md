ملخص كورس Claude Code 101 (غريب الشيخ)

1. ما هو Claude Code؟
• AI Agent (وكيل ذكاء اصطناعي): يعمل بنظام الحلقة التكرارية (Agentic Loop)، ولديه أدوات، ذاكرة، وقدرة على التخطيط لتنفيذ مهام برمجية مباشرة.
• الفرق عن الشات التقليدي: يمتلك وصولاً مباشراً لقراءة وتعديل الملفات، استخدام التيرمنال، تنفيذ الأوامر، وتثبيت الحزم دون الحاجة للنسخ واللصق.

2. طرق التشغيل
• تطبيق الديسكتوب (Windows / macOS).
• التيرمنال (CLI) داخل مجلد المشروع.
• إضافات محررات الأكواد (VS Code / JetBrains).
• واجهة الويب بالربط مع مستودعات GitHub.

3. أوضاع الصلاحيات (التبديل السريع عبر Shift + Tab)
• Default / Manual: موافقة مسبقة على كل تعديل أو أمر تيرمنال.
• Auto-Accept: تعديل الملفات تلقائياً مع طلب إذن لأوامر التيرمنال الحساسة.
• Plan Mode: وضع القراءة فقط (Read-only) للتخطيط وسؤال المستخدم عن التفاصيل قبل كتابة أي كود.

4. إدارة السياق والتوكنز (Context & Session)
• model/ و effort/: لاختيار النموذج وعمق التفكير.
• context/ لمعرفة المستهلك والمتبقي من نافذة السياق.
• compact/ لتلخيص المحادثة واستعادة مساحة السياق دون فقدان الفهم.
• clear/ و resume/ لبدء جلسة جديدة نظيفة أو العودة لجلسة سابقة.
• rewind/ للتراجع عن التعديلات في الكود والمحادثة لنقطة محددة مسبقاً.
• cost/ أو usage/ لتتبع استهلاك التوكنز والتكلفة.

5. ملف التوجيه CLAUDE.md
• يوضع في جذر المشروع (Root) ليكون بمثابة القواعد والدستور الثابت للمشروع (طريقة التشغيل، نمط الكود).
• يمكن إنشاؤه وتحديثه تلقائياً بأمر init/ أو initialize/.

6. المهارات والوكلاء الفرعيين (Skills & Sub-agents)
• Skills: ملفات تعليمات محددة لا تُحمَّل في السياق إلا عند الحاجة إليها بناءً على وصف المهمة (مثل front-end-design).
• يتم تصفح وتثبيت المهارات الرسمية عبر الأمر plugins/.
• إمكانية إنشاء Sub-agents لمهام متكررة مثل المراجعة التلقائية للكود (Code Reviewer).
