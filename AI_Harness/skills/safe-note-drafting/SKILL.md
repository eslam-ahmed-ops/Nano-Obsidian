# Skill: Safe Note Drafting

## Purpose

Prepare an AI-generated note draft while keeping it separate from the knowledge base.

## Procedure

1. Clarify the topic, source scope, and intended destination.
2. Gather only the necessary source material.
3. Write the draft under `AI_Harness/review/` by default.
4. Identify sources, assumptions, open questions, and possible duplication.
5. Check for filename conflicts before writing.
6. Mark the draft as requiring human review.
7. Log the actual task and validation.

## Constraints

Do not overwrite existing files or integrate into existing knowledge without explicit approval. Keep Harness content in English and preserve original Arabic names when references require them.
