# Operating Rules

1. Preserve the existing Vault and treat all existing notes and folders as user-owned.
2. Use English for every new Harness directory, filename, instruction, skill, template, log, and test document.
3. Preserve original Arabic folder and note names exactly when documenting them.
4. Inspect before changing. Check paths, conflicts, and intended scope before writing.
5. Make the smallest change that satisfies the request.
6. Keep drafts separate from approved knowledge. Place new AI-generated drafts under `AI_Harness/review/`.
7. Store every requested execution plan under `AI_Harness/plans/` before presenting it as final.
8. Label assumptions, unknowns, and incomplete validation.
9. Prefer reversible, narrowly scoped actions.
10. Record real execution and verified changes; do not invent completed work.
11. Ask for approval when an action crosses the permission boundary.
12. Do not treat this directory as a replacement for the knowledge base.
13. Do not assume `AI_Harness/AGENTS.md` applies outside `AI_Harness/`.
