# Vault Structure Guide

This guide describes the visible top-level structure without changing it. Arabic names below are preserved exactly as they appear in the Vault.

## Existing knowledge areas

- `المال والرزق`: an existing Arabic knowledge area whose detailed internal meaning should be confirmed from its notes before making assumptions.
- `ان يتقنه`: an existing Arabic knowledge area for material related to things to master; preserve the name exactly.
- `برمجة`: an existing Arabic programming and coding area; preserve its contents and naming.
- `عقل ثاني`: an existing Arabic second-brain or knowledge-management area; preserve its contents and naming.
- `علمًا نافعًا`: an existing Arabic beneficial-knowledge area; preserve its contents and naming.

The Vault may contain additional folders or notes at deeper levels. Folder meaning must be inferred cautiously from existing content and user guidance, never from renaming. The following names are protected examples and must remain unchanged if present: `وكلاء ذكاء اصطناعي`, `تقنية عجيبة`, `وجهات نظر`, `ملاحظات يومية`, `المكتبة`, `كورسات`, `روابط التعلم`, and `تطوير منصة تعليمية`.

## Harness area

`AI_Harness/` is a separate control and workflow layer. It is not a knowledge category and must not absorb or replace existing notes.

- `instructions/`: rules and reference guidance.
- `workflows/`: repeatable procedures.
- `tasks/`: task records and supporting briefs.
- `review/`: AI-generated drafts awaiting human review.
- `logs/`: factual execution and change records.
- `tests/`: Harness validation records.
- `skills/`: agent-compatible skill definitions.

When the exact meaning of an existing folder is unclear, report uncertainty and ask rather than renaming or reorganizing it.
