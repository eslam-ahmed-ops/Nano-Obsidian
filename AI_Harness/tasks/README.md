# Tasks

Use this directory for task briefs and task-specific supporting material. Keep filenames in English and use one clearly named subdirectory per substantial task when needed.

The current Vault improvement backlog is in [`VAULT_IMPROVEMENT_TASKS.md`](VAULT_IMPROVEMENT_TASKS.md). It is a proposal list only; each task requires the approval boundary in `../instructions/PERMISSIONS_POLICY.md` before existing knowledge notes are changed.

Each task record should state its purpose, scope, requested permissions, source paths, expected output, status, and validation result. Keep AI-generated drafts in `../review/` unless the user explicitly authorizes another location.

Do not copy or move existing knowledge notes into this directory.
