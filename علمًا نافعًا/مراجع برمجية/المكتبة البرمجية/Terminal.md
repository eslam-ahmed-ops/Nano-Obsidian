الدليل العملي الشامل لأوامر التيرمينال وتثبيت الحزم


1. فهم منطق المسارات (Paths)
• . : المجلد الحالي.
• .. : المجلد السابق (خطوة للأعلى).
• ~ : مجلد المستخدم الرئيسي (Home).
• / : الجذر الأساسي للنظام (Root).

───

2. التنقل واستكشاف الملفات (Navigation)
• pwd : إظهار المسار الكامل للمجلد الحالي.
• ls : عرض محتويات المجلد الحالي. 
◦ ls -l : تفاصيل الملفات (الحجم، الصلاحيات، التاريخ).
◦ ls -a : إظهار كل الملفات بما فيها الملفات المخفية (التي تبدأ بـ .).
◦ ls -la : دمج التفاصيل والملفات المخفية.
• cd &lt;folder> : الانتقال لمجلد معين (cd .. للرجوع للخلف، و cd ~ للـ Home).

───

3. إدارة الملفات والمجلدات (File Management)
• mkdir &lt;folder_name> : إنشاء مجلد جديد (mkdir -p a/b/c للمجلدات المتداخلة).
• touch &lt;file_name> : إنشاء ملف فارغ جديد.
• cp &lt;dest> : نسخ ملف (cp -r &lt;dir1&gt; &lt;dir2> لنسخ مجلد كامل).
• mv &lt;dest> : نقل ملف أو إعادة تسميته في مكانه.
• rm &lt;file_name> : حذف ملف نهائياً. 
◦ rm -r &lt;folder> : حذف مجلد بمحتوياته.
◦ rm -rf &lt;folder> : إجبار الحذف التام لمجلد بدون طلب تأكيد.

───

4. أوامر التنزيل وتثبيت الحزم (Download & Package Managers)

أ. تنزيل الملفات من الإنترنت عبر التيرمنال:
• curl -O : تنزيل ملف وحفظه بنفس اسمه الأصلي.
• curl -o &lt;new_name&gt; : تنزيل ملف وتسميته باسم محدد.
• curl -fsSL | bash : تحميل سكربت تثبيت وتشغيله مباشرة.
• wget : تنزيل مباشر للملفات (يدعم استكمال التحميل تلقائياً).

ب. مدراء حزم النظام (System Package Managers):
• Ubuntu / Debian / WSL:
◦ sudo apt update : تحديث قائمة الحزم والمستودعات.
◦ sudo apt install &lt;package_name> : تثبيت أداة جديدة.
◦ sudo apt remove &lt;package_name> : إزالة برنامج.
• macOS (Homebrew):
◦ brew install &lt;package_name> : تثبيت أداة جديدة.
◦ brew update && brew upgrade : تحديث الأدوات المثبتة.

ج. بيئات البرمجة الشائعة (Python / Node.js):
• Python (pip):
◦ pip install &lt;package_name> : تثبيت مكتبة بايثون.
◦ pip install -r requirements.txt : تثبيت كل مكتبات المشروع دفعة واحدة.
◦ pip uninstall &lt;package_name> : إزالة مكتبة.
• Node.js (npm / npx):
◦ npm install &lt;package_name> : تثبيت حزمة محلياً في المشروع.
◦ npm install -g &lt;package_name> : تثبيت أداة عامة على مستوى الجهاز.
◦ npx &lt;package_name> : تشغيل أداة برمجية مباشرة بدون تثبيتها دائماً.

د. التحكم في الإصدارات (Git):
• git clone &lt;repo_url> : تنزيل واستنساخ مشروع كامل من GitHub.

───

5. قراءة وعرض محتويات الملفات (Reading Files)
• cat &lt;file_name> : طباعة محتوى الملف كاملاً على الشاشة.
• less &lt;file_name> : تصفح محتوى ملف كبير صفحة بصفحة (اضغط q للخروج).
• head -n 10 &lt;file_name> : عرض أول 10 أسطر من الملف.
• tail -n 10 &lt;file_name> : عرض آخر 10 أسطر (tail -f للمتابعة الحية للسجلات).

───

6. البحث والتصفية (Search & Filter)
• grep "keyword" &lt;file_name> : البحث عن كلمة داخل ملف. 
◦ grep -r "keyword" . : البحث عن الكلمة في جميع ملفات ومجلدات المسار الحالي.
• find . -name "*.py" : البحث عن ملفات بالاسم أو الامتداد في المجلد وفروعه.

───

7. إدارة العمليات والأداء (Process Management)
• top أو htop : مراقبة حية لاستهلاك المعالج والذاكرة.
• ps aux : عرض جميع العمليات الجارية في الخلفية.
• kill : إنهاء عملية معينة برقم المعرّف الخاص بها.
• Ctrl + C : إيقاف فوري للعملية أو الأمر الشغال حالياً.
• Ctrl + Z : تعليق العملية مؤقتاً ونقلها للخلفية.

───

8. التوجيه وربط الأوامر (Redirection & Pipes)
• | (Pipe) : تمرير ناتج أمر ليكون مدخلاً لأمر آخر.
• > : حفظ ناتج الأمر في ملف (يمسح القديم).
• >> : إضافة ناتج الأمر في نهاية الملف دون مسح محتواه.

───

9. الصلاحيات وإدارة الجلسة (System & Permissions)
• clear أو Ctrl + L : تنظيف شاشة التيرمنال.
• history : استعراض سجل الأوامر السابقة.
• chmod +x &lt;script.sh> : إعطاء صلاحية التشغيل لملف تنفيذي.
• whoami : إظهار اسم المستخدم الحالي.
• exit : إغلاق جلسة التيرمنال.
