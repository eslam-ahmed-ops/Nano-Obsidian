1. أساسيات البناء بالنسخة المجانية
• الإمكانيات: يمكن بناء مواقع كاملة (HTML/CSS/JS/APIs) وهيكلتها بالكامل.
• القيود: حدود الاستخدام (Rate Limits) تتطلب فترات راحة للمشاريع الضخمة.
• النشر: الأكواد تُحفظ محلياً وتتطلب الرفع اليدوي لمنصات استضافة مجانية (Vercel / GitHub Pages).
2. إدارة المهارات (Skills) وتوحيد أسلوب العمل
لا حاجة لتكرار التعليمات في كل محادثة، يمكن فرضها تلقائياً عبر:
• نطاق النظام (Global): ملف rules.md في مسار ~/.antigravity/ لتطبيقه على كل المشاريع.
• نطاق المشروع (Local): ملف .antigravityrules أو CLAUDE.md داخل مجلد المشروع.
• التوافق: نصوص الـ Prompts وخوادم MCP متوافقة 100% بين Claude Code و Antigravity.

14. استراتيجيات معالجة "هلوسة الوكيل" (Agent Hallucination)
عندما يفقد الذكاء الاصطناعي تركيزه أو يبدأ بتخريب الكود:
• تفريغ السياق (Context Reset): اطلب ملخصاً لما تم، أغلق الجلسة، وافتح جلسة جديدة (أهم خطوة).
• تضييق النطاق: أمره بالتركيز على ملف أو ملفين فقط لمنع التشتت.
• الاحتكام للخطة: أعد توجيهه لملف task_plan.md ليعرف موقعه.
• التراجع الآمن: استخدام git restore للعودة لآخر نقطة مستقرة فوراً.
• الصدمة بالواقع: إعطاؤه رسالة الخطأ (Error Log) كما هي ليقوم بالإصلاح دون ابتكار.
15. مصفوفة توجيه الذكاء الاصطناعي (متى تستخدم أي استراتيجية؟)
• اطلب 3 حلول (عصف ذهني): عند القرارات المعمارية، تصميم الواجهات، والمقايضات (Trade-offs).
• استخدم الوكلاء الفرعيين (Sub-agents): للمشاريع الضخمة Full-Stack، مهام التنظيف الشامل، أو البحث في التوثيقات.
• خطوة بخطوة (تفاعلي): عند تتبع الأخطاء المعقدة (Debugging) أو إعدادات السيرفرات.
• دور الناقد (مراجعة): لاكتشاف الثغرات الأمنية، تحسين الأداء (Optimization)، والحالات الطرفية (Edge Cases).
• أوامر صارمة (Zero-Shot): للمهام الروتينية، الترجمة بين اللغات، وتوليد الأكواد النمطية (Boilerplate).
