# Data Types and Collections

## الأنواع الأساسية
- `int` للأعداد الصحيحة.
- `float` للأعداد العشرية.
- `str` للنصوص.
- `bool` للقيم المنطقية.

## المجموعات
- `list` مرتبة وقابلة للتعديل.
- `tuple` مرتبة وغير قابلة للتعديل.
- `dict` تربط المفتاح بالقيمة.
- `set` تخزن قيمًا فريدة.
